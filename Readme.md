## Bicyclious

![](assets/images/bicyclious_wordmark.png)

This is the source code for the Bicyclious website.  The content is a
Hugo website. The Bicyclious content is a demo site for the bikeshed
agent which is an assistant for the drudgery of running a bikeshed i.e.
a small collection of bikes and bikeparts, represented on the web.

There are build and publish "infrastructure as code" for publishing
the built Bicyclious Hugo site on sites like GitHub, Firebase, AWS,
Cloudflare, etc.
